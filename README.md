# Quiz Application

This is a web-based quiz application designed to test users' knowledge in an engaging way.

## Functionality

1.  **Interactive Questions:** Presents users with sentences containing blank spaces.
2.  **Answer Selection:** Provides four word options for users to fill in the blanks.
3.  **Answer Unselection:** Allows users to remove a selected word from a blank by clicking on it.
4.  **Timed Questions:** Implements a 60-second timer for each question.
5.  **Automatic Navigation:** Automatically advances to the next question when the timer expires.
6.  **Conditional Navigation:** Enables the "Next" button only after all blanks in a question are filled.
7.  **Data Source:** Fetches question data from a JSON API.
8.  **State Management:** Implements proper state management for application flow.
9.  **Feedback Screen:** Displays a summary at the end of the quiz, including:
    * All correct and incorrect answers.
    * The correct answers for incorrectly answered questions.
    * The user's score out of 10.

## Features

* **Interactive Questions:** Presents users with questions in a clear and interactive format.
* **Answer Selection:** Allows users to select answers from given options.
* **Real-time Timer:** Includes a timer to add a sense of urgency to the quiz.
* **Question Progression:** Guides users through a series of questions.
* **Result Display:** Shows the user's score and performance at the end of the quiz.

## Bonus Implementations

* **Dynamic Timer Color:** The timer's color changes to red when it counts down to 10 seconds, providing a visual cue to the user that time is running out.
* **Enhanced Result Page:** The result page displays correct answers in green and incorrect answers in red, making it easy for users to quickly assess their performance.

## Technologies Used

* **Frontend:** React
* **Backend:** JSON Server
